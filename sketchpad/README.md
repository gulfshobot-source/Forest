# Forest Sketchpad

This directory is the non-canonical experimental reservoir for The Forest.

## What belongs here

- raw handoffs from other AI systems;
- verbatim user-originated conceptual signals;
- unresolved language;
- research leads;
- competing hypotheses;
- speculative structures;
- mathematical models;
- visual grammars;
- contradiction registers;
- failed approaches that still carry information;
- prototype implementations and throwaway tests.

## What does not happen here

- persistence does not make an idea canonical;
- polished formatting does not increase truth status;
- AI-generated terminology does not replace user-originated language;
- a diagram does not become the ontology merely because it is easy to render;
- a prototype does not imply the canonical Forest has adopted its assumptions.

## Evidence lanes

Each major thread should preserve parallel lanes where useful:

1. `raw-signal` — exact source language and provenance.
2. `resonances` — tentative relationships and external precedents.
3. `open-questions` — ambiguity, contradiction, unknowns, and negative space.
4. `provisional-forms` — diagrams, equations, schemas, metaphors, prototypes.
5. `experiments` — empirical or implementation tests.
6. `promotion-candidates` — material that may be ready for canonical reconciliation.

## Promotion gate

Before material moves into `gulfshobot-source/the-forest`, verify:

- source and provenance are preserved;
- the proposal does not duplicate an existing canonical object;
- relevant contradictions have been surfaced;
- status is explicit: proposed / inferred / generated / observed / verified;
- its relationships to existing Forest architecture are understood;
- promotion improves the canonical system rather than merely expanding it.

The sketchpad is deliberately allowed to be larger, stranger, more contradictory, and less settled than the canonical Forest.

# Forest — Experimental Sketchpad / Incubator

This repository is the **experimental sketchpad, incubator, and research lab** for the canonical Forest.

Canonical system of record: `gulfshobot-source/the-forest`

## Role

Use this repository for material that is important enough to preserve but **not yet ready to become authoritative**.

Examples:

- raw AI-to-AI handoffs;
- emerging user language and conceptual seeds;
- competing interpretations;
- speculative architecture;
- mathematical probes;
- visual experiments;
- ontology and schema sketches;
- discarded approaches with residual signal;
- contradictions and unresolved questions;
- implementation spikes;
- prototype kernels and protocols;
- research notes that may later be promoted.

Persistence here does **not** imply truth, validation, canonicality, or implementation.

## Promotion path

`raw signal / experiment → sketchpad evidence → validation / reconciliation → deliberate promotion into gulfshobot-source/the-forest`

The canonical Forest should remain reconstructable, coherent, and authoritative. This repository exists to give the broader system a much larger conceptual reservoir without forcing immature structures into the source of truth.

## Operating rules

1. Preserve raw source language before interpretation.
2. Keep user-originated signal separate from AI-generated structure.
3. Record contradictions instead of silently resolving them.
4. Mark hypotheses, guesses, and speculative mappings explicitly.
5. Prefer reversible experiments over premature canonicalization.
6. Keep provenance for research, handoffs, diagrams, and derived ideas.
7. Promote only after comparison against existing canonical Forest state.
8. Never let this repository silently become a second canonical Forest.
